# 🏙️ Dubai Real Estate Analytics Dashboard | Excel

## 📌 Project Overview

This project presents an interactive Dubai Real Estate Analytics Dashboard built in Microsoft Excel using a synthetic dataset of 12,000 property transactions.

The dashboard analyzes real estate sales performance across developers, projects, areas, property types, buyer nationalities, payment methods and sales channels.

The project demonstrates practical skills in:

- Microsoft Excel
- Power Query
- Power Pivot
- DAX
- PivotTables
- PivotCharts
- Data Modeling
- Data Cleaning
- KPI Development
- Interactive Dashboard Design
- Business Analysis

> **Disclaimer:** This project uses synthetic data created for portfolio and learning purposes. Developer names such as Emaar, DAMAC, Nakheel, Binghatti, Sobha Realty and others are used only as categorical labels. The figures do not represent actual company or Dubai market performance.

# 🔎 Key Portfolio Insights

Some notable observations from the synthetic dataset include:

- Total portfolio sales value reached approximately AED 44.04B across 12,000 transactions.
- Average property value was approximately AED 3.67M.
- Average price was approximately AED 1,850 per Sq.Ft.
- Off-plan properties represented approximately 64.58% of transactions.
- Total commission generated was approximately AED 1.21B.
- Average transaction discount was approximately 4.51%.
- Palm Jumeirah ranked highest among the analyzed areas by sales value.
- Emaar ranked highest among the analyzed developers by sales value.
- Apartments represented the largest property-type transaction segment.
- Sales-channel transaction volumes were relatively balanced across Digital Lead, Property Portal, Referral, Broker and Direct channels.

These observations describe this synthetic portfolio and should not be interpreted as actual Dubai market statistics.
